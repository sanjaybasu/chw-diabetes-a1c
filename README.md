# Care Team Engagement and HbA1c Among Medicaid Enrollees With Diabetes

Replication code for *Association of Multidisciplinary Care Team Engagement With
Hemoglobin A1c Among Medicaid Enrollees With Diabetes: A Doubly-Robust Machine
Learning Analysis.*

This repository contains **code only**. Patient-level inputs are protected health
information and are not shared (see [`DATA_NOTE.md`](DATA_NOTE.md)). Result outputs
(JSON, figures) and the manuscript are not committed; they are regenerated by running
the pipeline. All analyses are deterministic (random seed 42).

## Pipeline

| Step | Script | Purpose |
|---|---|---|
| 1 | `code/extract_cohort.py` | Query the analytics warehouse (coredb) to build the analysis inputs in `data/raw/` (HbA1c labs, eligible universe for the IPCW denominator, status-event dates). Requires the base cohort `data/analytic_cohort.parquet` and a read-only database connection. |
| 2 | `code/analysis.py` | Primary estimate (mean HbA1c change, follow-up 90–365 days after index, by LinearDML on the propensity-score-trimmed cohort), covariate balance, propensity-score overlap, treatment-effect heterogeneity (generalized random forest, group average treatment effects, best linear projection, baseline-HbA1c interaction), baseline-HbA1c subgroups, E-value, negative-control placebo, HbA1c measurement-count distribution, inverse-probability-of-censoring weighting for follow-up availability, and a time-zero-aligned analysis with the identification-to-activation interval. Writes `output/results.json`. |
| 3 | `code/cost_effectiveness.py` | Translates the estimated HbA1c change (read from `output/results.json`) into 10-year complication and cost projections using the RECODe risk equations; probabilistic sensitivity analysis. Writes `output/cost_effectiveness.json`. |
| 4 | `code/figures.py` | Treatment-effect figure, propensity-score distributions, cost-effectiveness plane, participant flow, and sensitivity-analysis forest. Writes `output/figures/`. |
| — | `code/activity_outcome_analysis.py` | Exploratory association between specific care-team activities and HbA1c change within the treated group (hypothesis-generating; requires care-management-platform encounter data). |

```bash
pip install -r requirements.txt
python code/extract_cohort.py        # requires DB access; writes data/raw/ (PHI, git-ignored)
python code/analysis.py              # writes output/results.json
python code/cost_effectiveness.py    # writes output/cost_effectiveness.json
python code/figures.py               # writes output/figures/
```

## Methods summary

- **Estimator.** Doubly-robust debiased machine learning (EconML `LinearDML`): a
  gradient-boosted outcome model and a logistic treatment model with 5-fold
  cross-fitting; the estimate is consistent if either first-stage model is correct.
- **Outcome.** Change in mean HbA1c from baseline (6 months before index) to follow-up
  (mean of all values 90–365 days after index). A single most-recent value is a
  concordant prespecified sensitivity analysis.
- **Heterogeneity.** Generalized random forest (EconML `CausalForestDML`) with a best
  linear projection test and a parametric treatment-by-baseline-HbA1c interaction.
- **Robustness.** Inverse-probability-of-censoring weighting for differential follow-up
  availability; a time-zero-aligned analysis anchoring both groups at the identification
  date (most-proximate baseline); a grace-period target-trial emulation classifying
  treatment by activation within a fixed window of identification; a follow-up-window
  sensitivity grid; and an E-value.

See `DATA_NOTE.md` for input-data structure and provenance.
